# Kitden 0.9.0 — card stacks on the maps

Kitden 0.9.0 folds big groups on the Gateway and Library maps into small stacks of cards, so a large setup stays easy to scan, and both pages now open on the map at any size. The Context page is more exact: it shows the newest chat, shows how much of a cut skill description the agent got, and marks large skills in orange. `kitden open` also restarts a page left over from an older version.

## New

- **Card stacks on the Gateway and Library maps.** A group of two or more starts folded as a stack, and the tops of the first cards show their names. Press a stack to open it. A big group shows five cards at a time, with the next ones in a stack below and the ones you have seen in a stack above. **Collapse** folds an open group back. A change waiting in the tray never hides in a stack. ([#77](https://github.com/KonstantinStarovoytov/kitden/pull/77)) @KonstantinStarovoytov
- **Both pages open on the map at any size.** Before, they opened on the List past 15 servers, or 15 plugins and skills. ([#77](https://github.com/KonstantinStarovoytov/kitden/pull/77)) @KonstantinStarovoytov
- **How much of a cut skill description was sent.** On the "Cut short" side of Context, a skill shows a count such as "342 of 570" characters. Codex cuts from the end, so the agent sees only the start. ([#78](https://github.com/KonstantinStarovoytov/kitden/pull/78)) @KonstantinStarovoytov

## Better

- **Large skills stand out on Context.** On the side whose descriptions are sent, each skill and its piece of the bar go from grey to orange with the length of its description. The skill whose Details are open has a dark ring instead. ([#72](https://github.com/KonstantinStarovoytov/kitden/pull/72)) @KonstantinStarovoytov
- **Context shows the newest chat and checks itself against it.** Kitden takes the skill list with the latest time in the log, not the chat file changed last, so an old chat that the Codex app rewrites no longer wins. It uses the Codex window from `config.toml` and Codex's own rule for cutting descriptions, and it reads the skills the Claude app gives Claude Code. If the estimate does not match the chat, Kitden shows no estimate. ([#73](https://github.com/KonstantinStarovoytov/kitden/pull/73)) @KonstantinStarovoytov
- **A skill of a plugin updated after the chat is still counted.** Codex removes the old plugin folder on update, so Kitden reads the same file in the newest folder beside it, and says so. If the new description changes the result, the check fails and Kitden shows no estimate. ([#78](https://github.com/KonstantinStarovoytov/kitden/pull/78)) @KonstantinStarovoytov
- **Context knows Sonnet 5.5, Fable 5.2 and Haiku 5.5.** Chats on these models are sized as a 1M window, as Claude Code does, and the card names the model. Before, Kitden worked out the window from the list and sometimes showed no estimate. ([#81](https://github.com/KonstantinStarovoytov/kitden/pull/81)) @KonstantinStarovoytov
- **The plugin comes from released versions only.** Both plugin marketplaces now read the plugin from the `release` branch, so you get a plugin only after its Kitden version is out. ([#71](https://github.com/KonstantinStarovoytov/kitden/pull/71)) @KonstantinStarovoytov

## Fixed

- **`kitden open` works after an upgrade.** After `brew upgrade kitden` or `uv tool upgrade kitden`, a page that was already running lost its files, and its link answered with an error. The page now records its version. When `kitden open` finds a page of another version, or one from 0.8.0 or older, it stops it and starts a new one. If the old page does not stop, `kitden open` says so. ([#70](https://github.com/KonstantinStarovoytov/kitden/pull/70)) @KonstantinStarovoytov

## Documentation

- **README pictures show the card stacks.** The Library picture and the Gateway animation now show the 0.9.0 map. ([#82](https://github.com/KonstantinStarovoytov/kitden/pull/82)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`, then restart your agents once so
they start the new gateway. Run `kitden open` once after the update: a page that 0.8.0 or older
left running is stopped and started again. If you have both a uv and a Homebrew copy, `kitden
open` from the other copy restarts the page too. Requires macOS or Linux.

Nothing new goes online. The Context page reads, on your computer, what a client sent in your
last chats, the skills the Claude app gives Claude Code from the app's own folder, and Codex's
`config.toml` and `models_cache.json`. It keeps none of it. The page now also writes its version
into its own file in Kitden's data folder. See
[Privacy](https://github.com/KonstantinStarovoytov/kitden/blob/v0.9.0/PRIVACY.md).

Limits: the Context check was made on one real Codex list and two real Claude Code chats. Other
versions and Linux were not checked. The model window table and the built-in skill list are
hints, and Kitden shows no estimate when they do not match a chat.

Kitden is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.9.0/docs/development.md#check-before-a-release)
have not all been completed.
