# Kitden 0.3.0 — Your setup, connected

Kitden 0.3.0 brings your coding tools onto one map. Compare what your agents load,
share MCP servers through a local gateway and review changes before applying them.

## New

- **A home for your tools.** Use Library to compare what Claude Code, Codex and Cursor load. Switch between Map and List, inspect plugin contents and add missing plugins or skills. ([c8a30c3](https://github.com/KonstantinStarovoytov/kitden/commit/c8a30c3)) @KonstantinStarovoytov, ([4148223](https://github.com/KonstantinStarovoytov/kitden/commit/4148223)) @KonstantinStarovoytov, ([de70510](https://github.com/KonstantinStarovoytov/kitden/commit/de70510)) @KonstantinStarovoytov
- **Your own MCP gateway.** Share local or remote servers between clients. Choose which servers and tools each project can use; strict mode keeps newly discovered tools waiting for approval. ([af0edf4](https://github.com/KonstantinStarovoytov/kitden/commit/af0edf4)) @KonstantinStarovoytov, ([1b4e66c](https://github.com/KonstantinStarovoytov/kitden/commit/1b4e66c)) @KonstantinStarovoytov, ([9ce19e0](https://github.com/KonstantinStarovoytov/kitden/commit/9ce19e0)) @KonstantinStarovoytov

## Upgrade and limits

Install with `uv tool install --python 3.13 kitden`, or update an existing installation with
`uv tool upgrade kitden`. Requires macOS and uv. Start a new client session to load changed
settings; a tool switched off in the gateway is refused immediately in open sessions too.

Library replaces Load map and Discover. Scripts that used the removed `/api/catalog` route
need to use `/api/library-list` or `/api/library-offers` for their respective views.

Kitden is still alpha. Real-client and Keychain checks marked as pending in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.3.0/docs/development.md#check-before-a-release)
have not all been completed. Preview, backups and Undo protect settings; Undo cannot reverse
actions that a tool has already run. Undoing plugin removal reinstalls the plugin but cannot
restore its saved options.
