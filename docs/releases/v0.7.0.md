# Kitden 0.7.0 — see if your skills fit

Every chat starts with a list of your skills, and each client gives that list only a small
part of the context window. When the list is too long, the client quietly cuts or drops
descriptions. Kitden 0.7.0 adds a Context page that shows what your last chat really got. The
plugin also learned to audit a project. One test came from an outside contributor.

## New

- **Context: do your skills fit?** A new page shows what Claude Code and Codex sent in your last chat, read from the client's own chat log: which skills kept their description, showed only a name, were cut short or left out. Estimates for another window size, or for changes in the tray, show only while Kitden's copy of the client's rule rebuilds that last real list. Cursor publishes no limit, so its skills are listed without a verdict. ([c14f685](https://github.com/KonstantinStarovoytov/kitden/commit/c14f685)) @KonstantinStarovoytov
- **Set a skill to Name only or Off.** From a skill's Details on the Context page, set it to On, Name only (Claude Code) or Off. The change goes through the tray like every other: preview, Apply with a backup, Undo. ([52d5d8b](https://github.com/KonstantinStarovoytov/kitden/commit/52d5d8b)) @KonstantinStarovoytov, ([4ea90c6](https://github.com/KonstantinStarovoytov/kitden/commit/4ea90c6)) @KonstantinStarovoytov
- **Overview says when a skill list did not fit.** A card shows only when a last chat's list was cut. ([1621930](https://github.com/KonstantinStarovoytov/kitden/commit/1621930)) @KonstantinStarovoytov
- **The plugin can audit a project.** The new skill `audit` (`/kitden:audit` in Claude Code) has the agent compare what loads with the project you are in and list what to turn off. You make the changes on the page. ([9d90947](https://github.com/KonstantinStarovoytov/kitden/commit/9d90947)) @KonstantinStarovoytov

## Better

- **Name only is shown.** A skill set to Name only in Claude Code now says so in Library Details and in the MCP tools. ([e251a4f](https://github.com/KonstantinStarovoytov/kitden/commit/e251a4f)) @KonstantinStarovoytov
- **The sample shows the Context page.** `kitden demo` has a last chat for Claude Code and Codex, and the README has a picture of the page. ([230c525](https://github.com/KonstantinStarovoytov/kitden/commit/230c525)) @KonstantinStarovoytov, ([1c35167](https://github.com/KonstantinStarovoytov/kitden/commit/1c35167)) @KonstantinStarovoytov
- **The plugin's first skill is now `show-setup`.** The old name `setup` read like an installer. The plugin also has an icon. ([9d90947](https://github.com/KonstantinStarovoytov/kitden/commit/9d90947)) @KonstantinStarovoytov
- **The plugin's skill answers more questions.** It starts for questions that name MCP servers, skills, plugins, hooks or instruction files, and shows the install line when Kitden is missing. ([12c2907](https://github.com/KonstantinStarovoytov/kitden/commit/12c2907)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`, then start a new session in
your clients so they start the new gateway. Requires macOS or Linux.

The Context page knows the chat logs of Claude Code up to 2.1.311 and Codex up to
0.163.0-alpha.11. When a newer version's log has no list Kitden can read, the page says so and
does not guess. The window sizes of Sonnet 5.5,
Haiku 5.5 and Fable 5.2 are not in Kitden's table yet, so for them Kitden works the window out
from the list or shows the fact only. Kitden is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.7.0/docs/development.md#check-before-a-release)
have not all been completed.
