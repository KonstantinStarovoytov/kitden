# Kitden 0.10.0 — see if your skills fit

Kitden 0.10.0 makes `kitden scan` say whether your skills fit. Under each agent it prints one line about its skill list, taken from your last chat, and it ends by saying that nothing was changed. The README now leads with seeing what your agents load before changing anything, the guide tells how to stop using Kitden, and the AI policy says what the automated issues are.

## New

- **`kitden scan` says whether your skills fit.** Under each agent it prints one line about its skill list, such as "In your last chat on Oct 1, 4 of 20 skills showed only a name. The agent may not have used them." For Cursor it says that Kitden cannot see what Cursor sends, so it cannot tell. The answer is for the folder you run it in, and it is the same data as the Context page and `kitden show context`. The last line says "Nothing was changed". `kitden scan --json` prints what it printed before. ([#90](https://github.com/KonstantinStarovoytov/kitden/pull/90)) @KonstantinStarovoytov

## Documentation

- **The README leads with seeing.** It opens with "See what Claude Code, Codex and Cursor actually load, and which skills got cut." The parts now go from what Kitden shows to what it changes: whether your skills fit, the map, "Add what is missing", the gateway and undo. Get started begins with `uvx --python 3.13 kitden scan`, which only reads. The same line is now the description on PyPI, in the MCP Registry, in the plugin marketplace and in the tap's formula text. ([#91](https://github.com/KonstantinStarovoytov/kitden/pull/91)) @KonstantinStarovoytov
- **How to stop using Kitden.** The [guide](https://github.com/KonstantinStarovoytov/kitden/blob/v0.10.0/docs/guide.md#stop-using-kitden) has a new section, and the README links to it. ([#91](https://github.com/KonstantinStarovoytov/kitden/pull/91)) @KonstantinStarovoytov
- **The AI policy explains the automated issues.** [AI_POLICY.md](https://github.com/KonstantinStarovoytov/kitden/blob/v0.10.0/AI_POLICY.md) says that the `kitden-lantern` bot also opens issues, how to tell them from a person's (the label `automated`), that the bot never touches an issue without that label, and what `confirmed` and `false-alarm` mean. ([#87](https://github.com/KonstantinStarovoytov/kitden/pull/87)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`. You do not need to restart your agents for this release. With `uvx`, the new `scan` comes with this version. Requires macOS or Linux.

Nothing new goes online. `kitden scan` now does the context check on your computer: it reads what the clients sent in your last chats, the skills the Claude app gives Claude Code, and Codex's `config.toml` and `models_cache.json`, as the Context page does. It keeps none of it and prints one line per agent in your terminal. See
[Privacy](https://github.com/KonstantinStarovoytov/kitden/blob/v0.10.0/PRIVACY.md).

Limits: the Context check was made on one real Codex list and two real Claude Code chats. Other versions and Linux were not checked. When Kitden cannot tell, `scan` says why and does not guess. It does not yet say which skills load twice, or which one agent has and another lacks.

Kitden is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.10.0/docs/development.md#check-before-a-release)
have not all been completed.
