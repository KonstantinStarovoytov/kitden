# Kitden 0.8.0 — update from the page

Kitden 0.8.0 updates itself. When a new version is out, the page shows an Update button. After
your yes it runs the update, shows each real step and opens the new version, and the gateway
moves to it without breaking your agents' connection. This release also finds more in the
catalogs, keeps working when a client's files change shape, and adds privacy and security
pages.

## New

- **Update from the page.** When a newer Kitden is out, the rail shows an Update button beside the version. After your yes it runs `uv tool upgrade kitden` or `brew upgrade kitden`, shows each real step and reloads the page on the new version. Installs Kitden cannot update itself (uvx, pip, a source checkout) show the command to run instead. ([#64](https://github.com/KonstantinStarovoytov/kitden/pull/64)) @KonstantinStarovoytov
- **The gateway restarts in place.** The Kitden gateway moves to the new version by itself, and your agents keep their connection. ([#64](https://github.com/KonstantinStarovoytov/kitden/pull/64)) @KonstantinStarovoytov
- **A strip when an agent needs a restart.** After an Apply, an amber strip under the top bar names each client that must be restarted to see the change, with "Got it". Kitden never restarts an agent for you. ([#64](https://github.com/KonstantinStarovoytov/kitden/pull/64)) @KonstantinStarovoytov
- **Installed twice.** When both uv and Homebrew installed Kitden, a quiet line under the version says so, and Details shows how to remove one copy. ([#64](https://github.com/KonstantinStarovoytov/kitden/pull/64)) @KonstantinStarovoytov
- **Catalog search shows how many results there are.** Results come 60 at a time with Show more, and plugins come before skills, so a large source no longer hides them. ([#61](https://github.com/KonstantinStarovoytov/kitden/pull/61)) @KonstantinStarovoytov

## Better

- **Agents' `kitden` entries survive upgrades.** The entry Kitden adds to a client now runs the install's own launcher (uv's tool folder or Homebrew's `opt` link), so an upgrade does not break it. An old entry whose program is gone, or that points at a versioned Homebrew folder, gets an Update that changes only its command. ([#64](https://github.com/KonstantinStarovoytov/kitden/pull/64)) @KonstantinStarovoytov
- **Reads by shape, not by version.** The Context page reads a client's chat log whenever its skill list has a shape Kitden knows, whatever the client's version. A setting of an unexpected type reads as empty instead of hiding the whole client, and a Cursor switch of an unknown shape is reported. ([#54](https://github.com/KonstantinStarovoytov/kitden/pull/54)) @KonstantinStarovoytov
- **Clearer MCP tools.** Agents now pick `explain_item` when a request names one item, and its parameters have descriptions. ([#62](https://github.com/KonstantinStarovoytov/kitden/pull/62)) @KonstantinStarovoytov
- **The plugin's `install` skill no longer downloads and runs a script.** It shows the uv or Homebrew line and asks first, and it says that Kitden does not run on Windows. ([#52](https://github.com/KonstantinStarovoytov/kitden/pull/52)) @KonstantinStarovoytov

## Fixed

- **A GitHub source shows all its MCP servers.** The search stopped after 60 servers, before it matched the query; Show more now reaches them all. ([#61](https://github.com/KonstantinStarovoytov/kitden/pull/61)) @KonstantinStarovoytov
- **Many open tabs no longer hang a new one.** A tab in the background gives its live connection back. ([#64](https://github.com/KonstantinStarovoytov/kitden/pull/64)) @KonstantinStarovoytov

## Documentation

- **A privacy page and a security page.** [PRIVACY.md](https://github.com/KonstantinStarovoytov/kitden/blob/v0.8.0/PRIVACY.md) says what Kitden reads, what stays on your computer and when it goes online; the plugin links it. [SECURITY.md](https://github.com/KonstantinStarovoytov/kitden/blob/v0.8.0/SECURITY.md) says how to report a security problem in private. ([#53](https://github.com/KonstantinStarovoytov/kitden/pull/53), [#55](https://github.com/KonstantinStarovoytov/kitden/pull/55)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`, then restart your agents once so
they start the new gateway. Later updates from the page need no restart. If a gateway cannot
move to a new version by itself, it keeps working on the old one until the agent restarts.
Requires macOS or Linux.

To know whether a new version is out, the page asks PyPI (or, for a Homebrew install, the
Homebrew tap on GitHub) at most once a day, when it opens. The request carries Kitden's
version, and as with any web request they see your IP address. See
[Privacy](https://github.com/KonstantinStarovoytov/kitden/blob/v0.8.0/PRIVACY.md). `kitden
show` and `kitden mcp` never check.

Kitden is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.8.0/docs/development.md#check-before-a-release)
have not all been completed.
