Kitden 0.2.0 adds Discover, skills, and moving servers into an Obot or MetaMCP gateway. It also
has a new look and many fixes from a UX audit.

## New

- **Discover.** Search the plugins in the marketplaces already on this computer. Filter by
  category, marketplace, and added or not. Add a plugin to Claude Code and Codex in one review:
  the clients' own commands do the work, and Undo removes it again.
- **Add a marketplace** from a folder on this computer or a GitHub link.
- **Skills in Discover.** Copy a skill into a client, with Undo. A skill that needs its plugin
  points you to the plugin.
- **Every client the change reaches.** Add and Preview name Cursor when it loads Claude Code's
  plugins and skills, so nothing loads somewhere you did not expect.
- **Obot as your gateway.** Kitden reads what an Obot gateway holds and connects clients to it with
  OAuth or a key.
- **Move into the gateway.** Move a direct MCP server into Obot or MetaMCP, or move all of them,
  with one Apply and one Undo. Obot blocks servers on this computer or a private network, so
  Kitden says so before the review.
- **Switch gateways.** "Use this gateway…" moves every client to another gateway in one review.
- **Gateway diagram.** Click a client to open its app (when the app is installed), or the gateway
  to open its page. Hover a client to light its route and its direct entries.
- **New look.** The Kitden house, light and dark Graphite themes, and the Claude, Codex and Cursor
  icons. Calm motion shows what changed and where.

## Better

- Main pages show only a name, the client and an action. Addresses, paths and commands are in
  Details.
- Servers that could move into the gateway are under "Can improve" on Overview, not with the
  things that need attention.
- A file change in a review shows its size (+2 −1) before you open it.
- The Changes page keeps each change's restart and log-in notes under "To take effect".
- "Global settings" replaces "user scope", and the Load map says it shows saved settings.
- A plugin the page cannot change shows a locked switch with the reason.
- Kitden finds Codex inside the ChatGPT app when it is not on your PATH.
- Keyboard focus stays on the tab, filter or button you used when the page redraws, and arrow
  keys move between tabs.
- Buttons and switches are at least 24 px, and success and diff text are easy to read in both
  themes.
- A button that waits on Kitden shows a small spinner in its own place, and Apply of a change
  with several steps counts them ("Applying 2 of 5"). The line under the search box shows only
  for a slow scan, so it no longer blinks after each change.

## Fixed

- Move all into an Obot gateway no longer fails when Obot is busy.
- When the answer to Apply or Undo is lost, the page reads the change back and tells you how it
  ended, instead of reporting a failure.
- After a project switch, the page never shows the old project's data as the new one. When a
  refresh fails, it says how old the data is.
- Each gateway card shows only its own connections, and its connect form uses that gateway.
- Restart notes appear only for changes that happened.
- Cursor's own plugins say Installed. When a gateway cannot be read, Details says why Move is
  missing.
- Retry reads everything again, so the counts in the side rail are right.
