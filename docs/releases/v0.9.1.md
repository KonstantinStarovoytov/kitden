# Kitden 0.9.1 — see if your skills fit from the first command

Kitden 0.9.1 makes `kitden scan` answer the question people ask first: under each agent it now says whether your skills fit, and it ends by saying nothing was changed. The README now opens with what your agents load and which skills got cut, and the guide says how to stop using Kitden. The AI policy and the issue forms are new too.

## Better

- **`kitden scan` says whether your skills fit.** Under each agent it prints one line about its skill list, such as "In your last chat on Oct 1, 4 of 20 skills showed only a name." When Kitden cannot tell (Cursor, or no chat yet), the line says why. The command ends with "Nothing was changed: scan only reads your agents' settings." `kitden scan --json` prints the same as before. ([#90](https://github.com/KonstantinStarovoytov/kitden/pull/90)) @KonstantinStarovoytov
- **One new description everywhere.** The README, PyPI, the MCP Registry and the plugin marketplace all say: "See what Claude Code, Codex and Cursor actually load, and which skills got cut." ([#91](https://github.com/KonstantinStarovoytov/kitden/pull/91)) @KonstantinStarovoytov

## Documentation

- **The README leads with seeing.** It opens with what your agents load and which skills got cut. "See whether your skills fit" comes first, then the map, "Add what is missing", the gateway and undo. Get started begins with `uvx --python 3.13 kitden scan`, which only reads. ([#91](https://github.com/KonstantinStarovoytov/kitden/pull/91)) @KonstantinStarovoytov
- **How to stop using Kitden.** The guide has a new part, "Stop using Kitden", and the README links to it. ([#91](https://github.com/KonstantinStarovoytov/kitden/pull/91)) @KonstantinStarovoytov
- **The AI policy explains automated issues.** [AI_POLICY.md](https://github.com/KonstantinStarovoytov/kitden/blob/v0.9.1/AI_POLICY.md) says that the `kitden-lantern` bot also opens issues, how to tell them from a person's (the label `automated`), what `confirmed` and `false-alarm` mean, and that the pinned issue "Kitden desk" is written by a script, not an AI model. ([#87](https://github.com/KonstantinStarovoytov/kitden/pull/87)) @KonstantinStarovoytov
- **Forms for bugs and ideas.** A new issue opens a **Bug** form (Kitden version, system, client, steps, what happened) or an **Idea** form (what is hard today, what you suggest). A blank issue is still possible. ([#86](https://github.com/KonstantinStarovoytov/kitden/pull/86)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`. Agents need no restart for this
release. Requires macOS or Linux.

Nothing new goes online. `kitden scan` now also reads, on your computer, what a client sent in
your last chats for the current folder, as the Context page does, to print the skill-list line.
It keeps none of it. See
[Privacy](https://github.com/KonstantinStarovoytov/kitden/blob/v0.9.1/PRIVACY.md).

Limits: the skill-list line is as exact as the Context page. Kitden cannot see what Cursor
sends, so for Cursor the line says it cannot tell. The "Stop using Kitden" steps were not tried by
hand in all three clients.

Kitden is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.9.1/docs/development.md#check-before-a-release)
have not all been completed.
