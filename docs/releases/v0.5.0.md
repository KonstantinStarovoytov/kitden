# Kitden 0.5.0 — Linux, and safer by default

Kitden 0.5.0 runs on Linux as well as macOS, installs with Homebrew, and adds Python servers
from the MCP Registry. A review of the whole tool also made Apply, sign-in checks and the scan
safer.

## New

- **Kitden runs on Linux.** The page, the gateway and every change work on a Linux desktop as on a Mac. Server secrets go to your desktop keyring (GNOME Keyring or KDE Wallet) through `secret-tool`, and the page says "keyring" there. `install.sh` accepts Linux and installs Kitden from PyPI. Every check now also runs on Ubuntu, with one real keyring round trip. ## Fixed

- **A failed Apply puts everything back.** Any error during Apply restores every file it can, one failed restore no longer stops the others, and a secret already in the Keychain gets its old value back. "The original settings were restored" is said only when every file reads back as it was. ([7a645e5](https://github.com/KonstantinStarovoytov/kitden/commit/7a645e5)) @KonstantinStarovoytov, ([6c5daa2](https://github.com/KonstantinStarovoytov/kitden/commit/6c5daa2)) @KonstantinStarovoytov
- **A client's own changes survive Apply.** Each file is read again just before it is written, so a client that rewrites its file during Apply keeps its change. If the entry itself changed, Apply stops. ([8194332](https://github.com/KonstantinStarovoytov/kitden/commit/8194332)) @KonstantinStarovoytov
- **Sign-in checks stay outside.** When a server on the internet names an address on this computer or a private network in its sign-in answers, Kitden does not fetch it, in any spelling of the address. ([5cc6180](https://github.com/KonstantinStarovoytov/kitden/commit/5cc6180)) @KonstantinStarovoytov
- **The gateway key goes only to the gateway.** Kitden no longer follows a redirect or a proxy when it talks to Obot or MetaMCP. ([72e5124](https://github.com/KonstantinStarovoytov/kitden/commit/72e5124)) @KonstantinStarovoytov
- **A fixed secret tool.** An installed Kitden always runs `/usr/bin/security` or `/usr/bin/secret-tool`; the test variables work only from a source checkout. ([b05a424](https://github.com/KonstantinStarovoytov/kitden/commit/b05a424)) @KonstantinStarovoytov
- **A bad file no longer stops the scan.** A project file that is not UTF-8, nests too deep, is over 5 MB or is not a regular file shows as a problem of its own, and the rest is still listed. ([de90ba8](https://github.com/KonstantinStarovoytov/kitden/commit/de90ba8)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`, then restart your clients so
they start the new gateway. Requires macOS or Linux. On Linux, install `libsecret-tools`
(Debian, Ubuntu) or `libsecret` (Fedora, Arch) so Kitden can keep server secrets in your keyring.

Linux support is new. It is checked on Ubuntu in CI, with a real keyring, but has not yet
been tried by hand on a Linux desktop with Claude Code, Codex and Cursor. Kitden reads Cursor
and Claude Desktop from `~/.config` and does not follow `XDG_CONFIG_HOME`. Kitden is still
alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.5.0/docs/development.md#check-before-a-release)
have not all been completed.
