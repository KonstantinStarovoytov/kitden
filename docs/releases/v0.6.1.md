# Kitden 0.6.1 — a README in four parts, ready for the MCP Registry

Kitden 0.6.1 is a small release. The README tells the story in four parts, the package carries
the name the official MCP Registry checks, and three small things on the page are fixed. Two of
the fixes came from the first outside contributors.

## Better

- **README in four parts.** The map, find and add, the gateway, and why it is safe, with a picture of the catalog search. It names the Claude Code plugin. ([4380705](https://github.com/KonstantinStarovoytov/kitden/commit/4380705)) @KonstantinStarovoytov, ([2ee8fa6](https://github.com/KonstantinStarovoytov/kitden/commit/2ee8fa6)) @KonstantinStarovoytov, ([3f170be](https://github.com/KonstantinStarovoytov/kitden/commit/3f170be)) @KonstantinStarovoytov
- **Ready for the MCP Registry.** The package carries the name the official MCP Registry checks, `io.github.KonstantinStarovoytov/kitden`; `server.json` describes `kitden mcp` for the registry, and `glama.json` names the maintainer for Glama. @KonstantinStarovoytov

## Fixed

- **Copy results are announced.** Screen readers hear whether copying a command worked or failed, also on a second try. ([2fb9d2e](https://github.com/KonstantinStarovoytov/kitden/commit/2fb9d2e)) @sunxiuguo
- **No empty filters row.** The MCP add panel no longer shows an empty filters row above its results. ([a1aea37](https://github.com/KonstantinStarovoytov/kitden/commit/a1aea37)) @Zehraatalay
- **Ticks in line.** In the add panel, each agent's tick under Add to starts at the same edge. ([96308bc](https://github.com/KonstantinStarovoytov/kitden/commit/96308bc)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`. Requires macOS or Linux. Kitden
is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.6.1/docs/development.md#check-before-a-release)
have not all been completed.

**Full changelog:** https://github.com/KonstantinStarovoytov/kitden/compare/v0.6.0...v0.6.1
