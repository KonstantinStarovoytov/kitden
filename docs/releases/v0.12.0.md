# Kitden 0.12.0 — new: set the skill list limit on the Context page; turn off built-in skills

Kitden 0.12.0 lets you act on a skill list that ran out of room. On the Context page you drag the limit line to give Claude Code's or Codex's skill list more room, and Kitden shows what each step costs. You can also turn off the skills built into Claude Code, and a whole plugin, from the Context page. Kitden now counts skills that Claude Code lists with a command, and a skill can be turned off in one project beside your other skill rules.

## New

- **Set the skill list limit by dragging the limit line.** When skills showed only a name because the list ran out of room, the limit line on the skill list's bar has a handle. Click it for Details, or drag it (or use the arrow keys) to see what each step gives, such as "1.5% · all 20 fit · about 650 more characters per chat". It snaps at the first step where every description fits. Release adds a row to the tray, "Set to 1.5%", which previews, applies with a backup, is verified and can be undone. For Claude Code the steps are 1% (the default), 1.1%, 1.2%, 1.3%, 1.4%, 1.5%, 1.7%, 2%, 2.5%, 3%, 3.5% and 4% of the context window, written as `skillListingBudgetFraction` in `~/.claude/settings.json`. For Codex the steps are 500 tokens up to 10,000, written as `[skills] max_context_tokens` in `config.toml`. "Back to 1%" and "Back to the default" take the key out again. After Apply the page keeps the old chat's own limit on the bar and says the limit changed. Kitden does not offer a change when `SLASH_COMMAND_TOOL_CHAR_BUDGET` is set, when a project's or local file sets the share, or when even the largest step would not fit every description, and it says why. See "Upgrade and limits". ([#189](https://github.com/KonstantinStarovoytov/kitden/pull/189), [#190](https://github.com/KonstantinStarovoytov/kitden/pull/190), [#195](https://github.com/KonstantinStarovoytov/kitden/pull/195)) @KonstantinStarovoytov
- **Turn off the skills built into Claude Code, and whole plugins, from the Context page.** 13 built-in skills now have the same switch as your own (On, Name only, Off) for all projects. A plugin's skill or command offers "Turn off superpowers" in Details, and says what goes with it, such as "Turns off all of superpowers: 15 skills and 1 hook. About 1,681 fewer characters in the list." Skills that are off wait under Turned off and can be turned on again. A skill with no switch, such as one the Claude app adds, now says where it comes from and why it has none. The estimate stays when a skill was set to Off or Name only after the last chat. ([#193](https://github.com/KonstantinStarovoytov/kitden/pull/193)) @KonstantinStarovoytov

## Better

- **The limit control also works when Kitden cannot replay your last chat.** Before, a newer Claude Code often left the Claude Code card with no limit control. Now Kitden counts what all descriptions need and offers the smallest share that fits them. It says only what a count can say: a step reads "all 92 fit" or "not all fit", and Details say it is a count, not a replay. Skills added or turned on after the last chat count too, because your next chats list them. ([#191](https://github.com/KonstantinStarovoytov/kitden/pull/191)) @KonstantinStarovoytov
- **Turn a Claude Code skill off in one project beside other skill rules.** Kitden refused when your settings, or the project's shared file, already held a skill rule, with "Claude Code may not merge skill settings across files". It does merge them, so the refusal is gone. One preview can hold a rule for all projects and a rule for one project, and the review names only the projects whose own rule keeps the skill on. ([#194](https://github.com/KonstantinStarovoytov/kitden/pull/194)) @KonstantinStarovoytov

## Fixed

- **A skill that Claude Code lists with its command is read right.** Claude Code lists a skill as `name (command)` when the word you type is not the skill's name, such as `ship-local (ship)`. Kitden took such a skill for name only and added its whole line to the skill before it. Now both are read, and the command counts in the size of the list. On one real setup the number of skills that showed only a name went from 22 to 21 of 92, and the size of the list matched the chat's log. ([#192](https://github.com/KonstantinStarovoytov/kitden/pull/192)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`. The gateway did not change, so your agents need no restart. A skill list limit you set applies to chats that start after Apply; whether Codex needs a restart is not confirmed. Requires macOS or Linux.

Nothing new goes online. What Kitden writes and reads changes a little:

- After your Apply, Kitden writes `skillListingBudgetFraction` in `~/.claude/settings.json` (for all projects), or `[skills] max_context_tokens` in Codex's `config.toml`. Turning off a built-in Claude Code skill writes `skillOverrides` in the same file. Each change has a preview, a backup and Undo.
- To count what the next chats would list, Kitden reads the `SKILL.md` descriptions of skills that were added or turned on after your last chat, as it already reads descriptions for the page. It keeps none of it.

See [Privacy](https://github.com/KonstantinStarovoytov/kitden/blob/v0.12.0/PRIVACY.md).

Limits:

- Kitden has not been tried against a real Claude Code or Codex that reads a share it wrote in a new chat. Whether a running chat picks it up, and whether a project's `.codex/config.toml` or a profile overrides the Codex key, are open.
- A share already in your settings that is not one of the twelve, such as 4.5% or one written by hand, still works. Kitden shows it as the limit now and offers the listed shares above it, or "Back to 1%".
- When a limit changed after a chat and Kitden cannot tell which, the page draws no limit line for that chat.
- Turning a built-in skill off was checked with Claude Code 2.1.330 in print mode, not in the Claude app. Six built-in skills and the plugins the Claude app adds have no switch.
- Dragging back for Codex can leave an empty `[skills]` header when Kitden added the table.

Kitden is still alpha: the real-client checks in [Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.12.0/docs/development.md#check-before-a-release) have not all been completed.
