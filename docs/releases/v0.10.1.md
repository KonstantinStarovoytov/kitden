# Kitden 0.10.1 — see what a skill loses

Kitden 0.10.1 shows a skill's description on the Context page. The part your agent did not get is grey, so you see what a cut or Name only skill loses before you shorten it or turn it off. Context also shows your real last Codex chat again, and the README links to the desk and to kitden-sdlc.

## Better

- **A skill's Details on Context shows its description.** Kitden reads it from the skill's `SKILL.md`. The part the agent did not get is grey, with the line "Grey: the part the agent did not get." A skill sent whole has no grey. A skill cut short (Codex) is grey after the characters Codex sent. A Name only skill (Claude Code), or one left out, is grey from the start. `kitden show context` now also gives the description to your agent. See "Upgrade and limits". ([#135](https://github.com/KonstantinStarovoytov/kitden/pull/135)) @KonstantinStarovoytov

## Fixed

- **Context shows your real last Codex chat.** Context read an old Codex run instead of your last chat, because `codex exec` runs were taken for chats. They are skipped now. Chats handed over from ChatGPT were skipped before, and now count. ([#133](https://github.com/KonstantinStarovoytov/kitden/pull/133)) @KonstantinStarovoytov

## Documentation

- **The README links to the desk and to kitden-sdlc.** Under the badges there is an Open the desk button, and a line saying that reviews, tests and releases for Kitden run from kitden-sdlc. ([#134](https://github.com/KonstantinStarovoytov/kitden/pull/134)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`. Agents need no restart for this release. Requires macOS or Linux.

Nothing new goes online, and Kitden reads no new file: it already read each skill's `SKILL.md` to size the skill list. What changes is where the text goes. The Context page now shows a skill's description, and `kitden show context` (which the plugin's `context` skill runs) now prints it into the chat, so your agent and the company behind it see it. The descriptions are the text of your own skill files. Kitden does not replace secrets in them, so keep secrets out of a skill's description. `kitden scan` prints no descriptions. See [Privacy](https://github.com/KonstantinStarovoytov/kitden/blob/v0.10.1/PRIVACY.md).

Limits:

- The grey part was checked in the tests and on real Codex and Claude Code logs for counts (30 Codex skills cut, 3 Claude Code skills as Name only, no false cuts). The pictures come from the README sample, with a written description and a cut put in by hand.
- The Codex chat fix was checked on real Codex 0.169.0 logs. Other Codex versions are not checked.

Kitden is still alpha: the real-client checks in [Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.10.1/docs/development.md#check-before-a-release) have not all been completed.
