# Kitden 0.7.1 — the plugin's server only reads

Kitden 0.7.1 is a small release for the plugin. The plugin's MCP server now offers only Kitden's
four reading tools, so what the plugin says it does and what it does are the same thing. The
gateway keeps working through the connection you make on the page.

## New

- **`kitden mcp --read-only`.** With this flag the server offers only Kitden's own tools, which only read, and never the tools of servers in the gateway. The plugin starts the server this way. ([#50](https://github.com/KonstantinStarovoytov/kitden/pull/50)) @KonstantinStarovoytov

## Better

- **The gateway link is always the page's own entry.** The page no longer counts the plugin's server as a client's connection to the gateway, so Connect and Disconnect work the same for every client. ([#50](https://github.com/KonstantinStarovoytov/kitden/pull/50)) @KonstantinStarovoytov

## Documentation

- **The plugin README says what runs.** It names the one program the plugin starts, the four tools, what they read, prompts to try and what to do when the server fails. ([#50](https://github.com/KonstantinStarovoytov/kitden/pull/50)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`, then start a new session in
your clients so they start the new gateway. Requires macOS or Linux.

The plugin now needs Kitden 0.7.1 or later: with an older Kitden the client shows the plugin's
server as failed. Update Kitden first, then the plugin.

If your servers are in the gateway and a client had only the plugin, open the page and click
**Connect** for that client. A client with both the plugin and the page's connection shows
Kitden's four reading tools twice, once under each server.

Kitden is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.7.1/docs/development.md#check-before-a-release)
have not all been completed.
