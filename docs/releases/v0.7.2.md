# Kitden 0.7.2 — the plugin works without a server

Kitden 0.7.2 rebuilds the plugin. It no longer starts an MCP server: its skills run a new
read-only command, `kitden show`. The plugin also gets four new skills, and it offers to install
Kitden when the program is missing.

## New

- **`kitden show`.** Prints one read-only answer as JSON and exits: `setup`, `findings`, `item NAME`, `projects` or `context`. The answers are the same as the MCP server's. ([#51](https://github.com/KonstantinStarovoytov/kitden/pull/51)) @KonstantinStarovoytov
- **Skill `context`.** Ask "do my skills fit?" and the agent says whether the skill list is over the client's limit and which skills lost their description. In Claude Code it is also `/kitden:context`. ([#51](https://github.com/KonstantinStarovoytov/kitden/pull/51)) @KonstantinStarovoytov
- **Skill `before-install`.** Before you add a server, plugin or skill, the agent looks whether a client already has it. ([#51](https://github.com/KonstantinStarovoytov/kitden/pull/51)) @KonstantinStarovoytov
- **Skills `open` and `install`.** One opens the Kitden page. The other installs or updates Kitden with uv, Homebrew or the install script; it shows the line and asks first. ([#51](https://github.com/KonstantinStarovoytov/kitden/pull/51)) @KonstantinStarovoytov

## Better

- **The plugin has no MCP server.** It adds only skills, so a client no longer shows a failed server when Kitden is missing, and Kitden's reading tools no longer show twice next to the gateway. `kitden mcp` itself is unchanged. ([#51](https://github.com/KonstantinStarovoytov/kitden/pull/51)) @KonstantinStarovoytov

## Documentation

- **The plugin README is rewritten.** It lists the six skills, what they read, prompts to try and what to do when Kitden is missing. ([#51](https://github.com/KonstantinStarovoytov/kitden/pull/51)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`, then start a new session in
your clients so they start the new gateway. Requires macOS or Linux.

The plugin now needs Kitden 0.7.2 or later. Update Kitden first, then the plugin. After the
plugin update the server `kitden` from the plugin is gone. If you want Kitden's reading tools as
an MCP server, add `kitden mcp` yourself or click **Connect** on the page.

Kitden is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.7.2/docs/development.md#check-before-a-release)
have not all been completed.
