# Kitden 0.11.0 — choose which clients Kitden reads

Kitden 0.11.0 lets you turn clients off. If you use only Claude Code, a button called **Choose clients…** at the top right of the page switches Codex and Cursor off, and Kitden stops reading them. This release also makes `kitden scan` print its counts in plain words, picks a project faster, and cleans up the words on the Overview, Library, Gateway and Context pages.

## New

- **Choose which clients Kitden reads.** **Choose clients…** is a button at the top right of the Overview, the Library, the Gateway and the Context page. It opens a panel with a switch for Claude Code, Codex and Cursor. A client you turn off is not read, not shown and not offered anything: not on the page, in `kitden scan`, in `kitden show` or in the agent tools. With Codex off, the wait for `codex plugin list` is gone. A switch acts at once, with no Apply, because no client file is written. A toast says "Kitden no longer reads Codex." with Undo. One client always stays on. A client now has three states: found, not found, off. `kitden scan` prints `Codex: turned off in Kitden`, and each page says which clients are off. Nothing in the client's own files changes, and a client that is off keeps its `kitden` entry and keeps working. Undo of an earlier change to an off client waits with "Turn Codex on to undo this." See "Upgrade and limits". ([#171](https://github.com/KonstantinStarovoytov/kitden/pull/171), [#172](https://github.com/KonstantinStarovoytov/kitden/pull/172)) @KonstantinStarovoytov

## Better

- **`kitden scan` prints its counts in plain words.** The counts read `MCP servers: 12`, `Hooks: 1` and `Skills: 62` where they read `mcp_server: 12`. The `Skills` line says why it differs from the chat's count: "62 on this computer; a chat lists one project's and Claude Code's own". The Claude Desktop Code tab is one line under Claude Code. A client that is not installed reads `Codex: not found`. A line no longer breaks inside `kitden show findings` or "+26 more". `scan --json` does not change. ([#168](https://github.com/KonstantinStarovoytov/kitden/pull/168)) @KonstantinStarovoytov
- **Picking a project is quicker.** When a project is picked, Kitden used to read every newer Claude Code chat log in full. It now reads a log in full only when it can hold a newer skill list than the best one so far. On one real setup the read of the logs went from 3.9 s to 1.0 s, and the answer is the same. ([#172](https://github.com/KonstantinStarovoytov/kitden/pull/172)) @KonstantinStarovoytov
- **The Overview opens fast with many projects.** To count the projects with rules of their own, it built the whole Library map for each one. It now checks only the rules: about a second where it took 12 seconds for 26 projects. ([d45ccfd](https://github.com/KonstantinStarovoytov/kitden/commit/d45ccfd)) Amanda Woodward
- **The Overview says what it is.** Its title is "Overview", and its lede names your clients. Notes with the same words fold into one row, such as "46 items load from another client." The Library and Gateway ledes say what the page is. ([f59e749](https://github.com/KonstantinStarovoytov/kitden/commit/f59e749), [6d660a3](https://github.com/KonstantinStarovoytov/kitden/commit/6d660a3)) Amanda Woodward
- **The Library says what each client loads.** A client's block says what it loads, not "Connected", and says why a client has no instruction file. The blocks are wide enough for those words. ([2c8834b](https://github.com/KonstantinStarovoytov/kitden/commit/2c8834b), [dfe9d27](https://github.com/KonstantinStarovoytov/kitden/commit/dfe9d27)) Amanda Woodward
- **Smaller touches on the pages.** A search on the Library or Gateway map scrolls to its first match. A skill's pill on the Context page says what its number is, and a plugin's skill shows its plugin. A change of several rows reads in the past tense. The Changes link shows no count. The empty Instructions map says "No instruction files here." only when no note already says why. ([a0d63a7](https://github.com/KonstantinStarovoytov/kitden/commit/a0d63a7), [2586fcc](https://github.com/KonstantinStarovoytov/kitden/commit/2586fcc), [d456100](https://github.com/KonstantinStarovoytov/kitden/commit/d456100), [#172](https://github.com/KonstantinStarovoytov/kitden/pull/172)) Amanda Woodward, @KonstantinStarovoytov

## Fixed

- **A plugin update no longer makes a skill count as cut.** When Codex updated a plugin after your last chat and a skill's description changed with it, Kitden compared the chat's text with the new one and said it was cut. A real setup showed "31 of 61 descriptions were cut" for 30 real cuts. Now Kitden leaves that skill out of the count, says it cannot tell for it, and the check against Codex's rule passes again. ([#166](https://github.com/KonstantinStarovoytov/kitden/pull/166)) @KonstantinStarovoytov
- **A client block on the Library map agrees with what is under it.** On the Instructions tab it counted commands and agents as files, so a block could say "2 files" above "Claude Code loads no instruction file". It now counts instruction files, and says "Commands and agents only" when that is all a client reads. On the Plugins and skills tab, a client whose only item is a hook said "Nothing loaded"; it now says "1 hook". ([ea775af](https://github.com/KonstantinStarovoytov/kitden/commit/ea775af)) Amanda Woodward
- **The hint line no longer lies over page text.** The strip is solid under its words. ([3a8db63](https://github.com/KonstantinStarovoytov/kitden/commit/3a8db63)) Amanda Woodward
- **A skill reached twice counts once in `kitden scan`.** A project listed by its path and by a symlink to it counted its skills two times. ([#168](https://github.com/KonstantinStarovoytov/kitden/pull/168)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`, then restart your agents once so they start the new version and its tools. Requires macOS or Linux.

Nothing new goes online. What changes is what Kitden stores: which clients you turned off is kept in one small file, `clients.json`, in Kitden's own data folder (for example `{"off": ["codex"]}`). A missing or broken file means no client is off. It is Kitden's own choice, not a client's settings. The faster project pick reads the same Claude Code chat files as before and keeps none of them. See [Privacy](https://github.com/KonstantinStarovoytov/kitden/blob/v0.11.0/PRIVACY.md).

Limits:

- A client that is off is only not read. If it already uses the Kitden gateway, it keeps working. Turning it off does not disconnect it.
- A note that Cursor loads a skill from Claude Code's folder still names Claude Code when Claude Code is off.
- Choose clients… was tried on sandbox homes and the demo, not on a real setup with a narrow window or reduced motion.
- The `kitden scan` changes were run on sandbox homes only.

Kitden is still alpha: the real-client checks in [Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.11.0/docs/development.md#check-before-a-release) have not all been completed.
