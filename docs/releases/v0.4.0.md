# Kitden 0.4.0 — Add anything, sign in once

Kitden 0.4.0 turns the page into a place to find and add what your agents load. Search the
catalogs you already use, drag several servers in at once, and let Kitden handle tokens and
browser sign-in, all before you press Apply.

## New

## Upgrade and limits

Update with `uv tool upgrade kitden`, then restart your clients so they start the new gateway.
Requires macOS and uv. Secrets go to the macOS Keychain only.

Browser sign-in uses the MCP authorization flow (OAuth 2.1 with PKCE) and needs a server whose
authorization server allows dynamic client registration; otherwise Kitden asks for an API key.
Kitden is still alpha: browser sign-in was checked with real servers, but the real-client checks
marked as pending in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.4.0/docs/development.md#check-before-a-release)
have not all been completed. Two different servers with the same name cannot both be held yet.

### Small fixes and internal changes

This release also tidies the code: duplicated helpers are shared, dead code is gone and the
behaviour is unchanged.
