# Kitden 0.9.2 — say exactly what scan changes

Kitden 0.9.2 makes `kitden scan` say exactly what it leaves alone: it now ends with "Your agents' settings were not changed: scan only reads them." The line in PyPI and the MCP Registry names MCP servers and plugins again, and "Stop using Kitden" now uses the page. The guide says more about what `scan` reads.

## Better

- **The catalog line names MCP servers and plugins again.** PyPI and the MCP Registry now say: "See the MCP servers, plugins and skills Claude Code, Codex and Cursor load, and which skills got cut". The line from 0.9.1 had dropped "MCP servers" and "plugins", the words people search by. The README's first line and the Homebrew line stay as they are. ([#94](https://github.com/KonstantinStarovoytov/kitden/pull/94)) @KonstantinStarovoytov

## Fixed

- **`kitden scan` no longer says "Nothing was changed".** `scan` keeps one file of its own, `versions.json` in Kitden's data folder, so the old closing line said more than was true. It now ends with "Your agents' settings were not changed: scan only reads them." ([#94](https://github.com/KonstantinStarovoytov/kitden/pull/94)) @KonstantinStarovoytov

## Documentation

- **The guide says what `scan` reads and keeps.** For the folder you run it in, `scan` reads the last chat, asks each agent for its version and asks Codex for its plugin list. It keeps the versions in one file in Kitden's data folder. The README says the same. ([#94](https://github.com/KonstantinStarovoytov/kitden/pull/94)) @KonstantinStarovoytov
- **"Stop using Kitden", step 2, uses the page.** It said to remove the `kitden` server by hand. It now says to open each agent's Details in **Gateway** and press **Disconnect from the gateway…**, which takes the `kitden` entry out. ([#94](https://github.com/KonstantinStarovoytov/kitden/pull/94)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`. Agents need no restart for this
release. Requires macOS or Linux.

Nothing new goes online, and Kitden reads nothing new. The privacy page now names a file that
Kitden already kept: the versions it finds for each client, in `versions.json`, one small file
in Kitden's own data folder. See
[Privacy](https://github.com/KonstantinStarovoytov/kitden/blob/v0.9.2/PRIVACY.md).

Limits: "Disconnect from the gateway…" was checked in the code, not tried by hand in the three
real clients.

Kitden is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.9.2/docs/development.md#check-before-a-release)
have not all been completed.
