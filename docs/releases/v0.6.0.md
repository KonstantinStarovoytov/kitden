# Kitden 0.6.0 — tokens, hover words and several tools at once

Kitden 0.6.0 lets you give a server in the gateway the token or header it needs, says when a
server turns calls down for lack of one, and lets you pick several tools and turn them off in
one change. Hover words now explain what a button leaves out. A review of the whole tool also
made Undo, Apply and secrets safer.

## New

- **Add access to a server in the gateway.** A server's Details always show Access. **Add access…** adds a token (sent as `Authorization: Bearer`), a header of its own, a browser sign-in, or a variable for a local server. It goes through the preview with a backup and Undo, and the value goes to your Keychain or keyring. A server that answers without the value says its first call checks it. ([00e8cad](https://github.com/KonstantinStarovoytov/kitden/commit/00e8cad)) @KonstantinStarovoytov, ([e928ccd](https://github.com/KonstantinStarovoytov/kitden/commit/e928ccd)) @KonstantinStarovoytov
- **Needs token.** A server that starts without a token but turns its calls down (HTTP 401 or 403) shows "Needs token" on the map, its Details lead with Add access…, and the agent is told where to add one, not just "the call failed". ([00e8cad](https://github.com/KonstantinStarovoytov/kitden/commit/00e8cad)) @KonstantinStarovoytov
- **Pick several tools.** In a server's Details, and on the Gateway map: Cmd or Ctrl and a click picks one more tool, Shift a run, and a band drawn over the tools picks them. Turn off or Turn on changes them all in one row of the preview; Space does the same and Escape lets them go. On the map the buttons sit in the hint line, so Details need not be open. ([d911c8e](https://github.com/KonstantinStarovoytov/kitden/commit/d911c8e)) @KonstantinStarovoytov, ([c7edd58](https://github.com/KonstantinStarovoytov/kitden/commit/c7edd58)) @KonstantinStarovoytov, ([2393571](https://github.com/KonstantinStarovoytov/kitden/commit/2393571)) @KonstantinStarovoytov

## Better

- **Hover words that add something.** Buttons whose label leaves something out explain it when you point at them, in the page's own popover look: "Move all 3…" says it moves every server that can move, in one change. Labels that say it all, names already on screen and a switch's state get none. ([0f46b99](https://github.com/KonstantinStarovoytov/kitden/commit/0f46b99)) @KonstantinStarovoytov, ([c942760](https://github.com/KonstantinStarovoytov/kitden/commit/c942760)) @KonstantinStarovoytov, ([3ec6cf6](https://github.com/KonstantinStarovoytov/kitden/commit/3ec6cf6)) @KonstantinStarovoytov
- **No Add that cannot work.** A client that cannot take a server (Claude Code has no start folder setting; Codex cannot use an SSE connection) gets one line that says why, on the Gateway and in the Library, in place of an Add button that would be refused. ([c942760](https://github.com/KonstantinStarovoytov/kitden/commit/c942760)) @KonstantinStarovoytov
- **Short project lists.** A tool's sentence names up to two projects; more are counted ("except 9 projects, where it is off"), with their names on hover. ([c942760](https://github.com/KonstantinStarovoytov/kitden/commit/c942760)) @KonstantinStarovoytov
- **No flicker.** A button says "In preview" only once the preview has its change, so a change refused at once no longer makes it jump. ([c942760](https://github.com/KonstantinStarovoytov/kitden/commit/c942760)) @KonstantinStarovoytov
- **The Kitden house in List.** The Kitden gateway's tile shows its house, not "GW". ([2393571](https://github.com/KonstantinStarovoytov/kitden/commit/2393571)) @KonstantinStarovoytov

## Fixed

- **Undo in a safe order, and again.** Undo takes servers out of a gateway last, once the client files read back as before, so a server is never in neither place. An Undo that stopped keeps its Undo button and can be pressed again. ([f0667d0](https://github.com/KonstantinStarovoytov/kitden/commit/f0667d0)) @KonstantinStarovoytov
- **A crash during Apply is found.** A change is saved as Applying before its first write; at the next start such a record says "Kitden stopped during Apply" and names the files to compare with their backups. ([efb66e6](https://github.com/KonstantinStarovoytov/kitden/commit/efb66e6)) @KonstantinStarovoytov
- **Cancel forgets secrets.** Cancelling a preview, or an Apply that stops because a file changed, clears the secrets typed for it. ([204e07d](https://github.com/KonstantinStarovoytov/kitden/commit/204e07d)) @KonstantinStarovoytov
- **Exact versions only.** A registry server runs only at an exact version; `owner/repo`, `./dir`, tags and ranges are refused. ([5fa9639](https://github.com/KonstantinStarovoytov/kitden/commit/5fa9639)) @KonstantinStarovoytov
- **Plugin servers stay outside too.** A plugin or catalog server whose address is on this computer or a private network is not asked before Apply. ([af11bb7](https://github.com/KonstantinStarovoytov/kitden/commit/af11bb7)) @KonstantinStarovoytov
- **Client commands end cleanly.** A client's own command runs with no input; after 60 seconds it is stopped with every helper it started. ([8677334](https://github.com/KonstantinStarovoytov/kitden/commit/8677334)) @KonstantinStarovoytov
- **Preview refuses, never fails.** A file a change would read but cannot gives "Kitden could not read …" instead of an error. ([3405fc5](https://github.com/KonstantinStarovoytov/kitden/commit/3405fc5)) @KonstantinStarovoytov
- **Gateway settings kept.** Adding a gateway when Kitden cannot read its own settings is refused instead of replacing the file. ([30ec4e0](https://github.com/KonstantinStarovoytov/kitden/commit/30ec4e0)) @KonstantinStarovoytov
- **No values in logs.** File and gateway edits keep their values out of their printed form, so a traceback cannot show a secret. ([ba0ec5c](https://github.com/KonstantinStarovoytov/kitden/commit/ba0ec5c)) @KonstantinStarovoytov

## Upgrade and limits

Update with `uv tool upgrade kitden` or `brew upgrade kitden`, then start a new session in
your clients so they start the new gateway. Requires macOS or Linux.

Add access cannot check a token when the server answers its first request without one (agent-docs
does); the first call through the gateway checks it, and the map says "Needs token" if it is
wrong. Picking tools on the map works on the tools of the server whose Details are open. Kitden
is still alpha: the real-client checks in
[Development](https://github.com/KonstantinStarovoytov/kitden/blob/v0.6.0/docs/development.md#check-before-a-release)
have not all been completed.
