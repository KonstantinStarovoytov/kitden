# The motion mockup

The owner's clickable mockup of the map pages, version 11 (2026-10-24). It is the target for how
Kitden looks, moves and behaves. It is a reference only: nothing here ships.

- `kitden-motion.html`: open it in a browser. It uses fake data and loads its fonts and icons from
  the web, which the product must not do.
- `motion-spec.md`: every motion in the mockup, with times and curves (Calm values).
- The same design as frames: `design/kitden.pen` (the owner's file, not tracked).

The plan that moves the product to it: [2026-10-24-mockup-alignment.md](../superpowers/plans/2026-10-24-mockup-alignment.md).
