# Security

## Report a problem

Found a security problem in Kitden or its plugin? Please do not open a public issue. Report it
in private at https://github.com/KonstantinStarovoytov/kitden/security/advisories/new.

Say what you did, what happened and which version you run (`kitden --version`).

## What happens next

Kitden has one maintainer. You get an answer as soon as they can read the report. A confirmed
problem is fixed in a new release, and the release notes say so.

## Which version gets fixes

The latest release only. Update before you report.
