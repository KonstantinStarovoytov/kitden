# Code of Conduct

Kitden is a small project. Be kind and patient with everyone who writes here, in issues, pull
requests and discussions.

- Talk about the work, not the person.
- No harassment and no insults.
- Do not publish someone's private information.
- Remember that people write in a second language, or have little time. Ask if something is
  unclear.

The maintainer may edit, hide or remove comments that break these rules. They may block
someone who keeps breaking them.

## Report a problem

Report it in private, the same way [SECURITY.md](SECURITY.md) says to report a security
problem. Please do not report it in a public issue.

This page follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
